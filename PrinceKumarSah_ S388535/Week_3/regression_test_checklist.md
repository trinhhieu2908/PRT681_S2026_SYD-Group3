# Week 3 – Regression Testing Checklist

**Role:** Data Analyst & Tester

Use this checklist whenever search, filtering, job data, or job-detail functionality
is changed.

## Search
- [ ] Exact keyword search still returns relevant results.
- [ ] Partial keyword search still works.
- [ ] No-result search displays a clear message.
- [ ] Empty search does not cause an error.

## Filtering
- [ ] Location filter works.
- [ ] Employment type filter works.
- [ ] Category filter works.
- [ ] Multiple filters work together.
- [ ] Clear/reset filters restores the default result set.

## Job Details
- [ ] Job title is correct.
- [ ] Company is correct.
- [ ] Location is correct.
- [ ] Employment type is correct.
- [ ] Salary information is displayed correctly when available.
- [ ] Application link works.

## Data Quality
- [ ] No unintended duplicate listings.
- [ ] Required fields are present.
- [ ] Salary ranges are valid.
- [ ] Category values remain consistent.
- [ ] Location values remain consistent.
